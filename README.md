# RPGBox

RPGBox 是一个本地优先的 RPG 对话游戏客户端，面向单主角、多 NPC 的互动剧情。它使用 React、TypeScript 和 Capacitor 构建，主要运行于 Android，也支持在桌面浏览器中进行开发和调试。

## 功能

- 支持多个 RPG 存档之间切换、编辑、克隆、导入和导出
- 支持多个 OpenAI 兼容接口配置，并可从接口获取可用模型
- 可在每个 RPG 中独立选择接口、模型和生成参数
- 支持流式生成、停止生成、回滚最近五轮对话
- 支持四个可点击、可组合的剧情选项，也支持完全自定义行动
- 支持旁白、角色对话、主角对话和最多四名角色立绘
- 每个 RPG 可独立启用 NSFW 模式，新建时默认关闭
- 启用后，角色立绘支持常规 / NSFW 分组、默认立绘和多个状态标签
- 支持章节记忆、远期记忆、手工总结和自动压缩
- 支持可选的角色状态栏规则，由 AI 输出状态并由客户端自动更新
- 支持历史记录、AI 原文 Debug 查看和完整拼接提示词查看
- 应用固定竖屏显示，API 配置保存在本地

## 开发环境

- Node.js
- pnpm
- JDK 21
- Android SDK，至少包含 API 35 和 platform-tools

安装依赖：

```powershell
pnpm install
```

启动网页开发服务器：

```powershell
pnpm dev
```

运行测试和生产构建：

```powershell
pnpm test
pnpm build
```

## Android 构建

同步 Web 资源并构建 Debug APK：

```powershell
pnpm android:apk
```

生成的 APK 位于：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

也可以使用 Android Studio 打开 `android/` 目录进行调试。连接 Android 手机时，需要开启开发者选项和 USB 调试。

## AI 接口

RPGBox 使用 OpenAI 兼容的接口格式，需要配置：

- Base URL
- API Key
- 模型名称

Base URL 可以填写带或不带 `/v1` 的地址。全局设置负责管理接口和密钥；RPG 设置只负责选择接口、模型及温度、Top P、最大输出 Token、上下文轮数等参数。

## 客户端输出协议

AI 回复应使用纯文本协议，每行只承担一种类型：

```text
[状态] 地点：旅店；时间：夜晚；章节：旅店疑云；场景：延续
[旁白] 雨声敲打着窗户。
维纳斯（疑惑）：你也听到了吗？
[选项A] 继续询问声音的来源
[选项B] 检查旅店入口
[选项C] 让维纳斯留在原地
[选项D] 暂时离开旅店
```

启用状态栏规则后，四个选项之后可以继续输出：

```text
[维纳斯]状态：情绪：警惕；衣着：整齐
```

客户端会解析状态、选项、角色、场景和章节信息。状态行不会显示在剧情正文中，而是用于更新角色状态栏。

启用 RPG 的 NSFW 模式后，状态行会额外包含“模式：常规 / NSFW”。关闭时，NSFW 规则、设置和专用立绘不会进入系统提示词或游戏界面，但已有数据仍会保留，重新开启后可以继续使用。

## 记忆机制

- 当前章节内容保存在主记忆中
- 最近若干章节的摘要保留在主记忆列表中，默认最多五章
- 超出保留数量的章节会压缩到远期记忆
- 章节名由 AI 根据活动主题判断；引子和章节间过渡可以不设置章节名
- 用户可以在记忆界面手工总结、编辑或整理两类记忆
- 回滚对话时，相关记忆、章节状态和角色状态栏会一并恢复

## 数据与安全

RPGBox 默认将 API 配置、对话、记忆和立绘保存在本地设备中。API Key 当前使用 Capacitor Preferences 保存，正式用于不可信设备前，建议改为 Android Keystore 支持的加密存储。

不要将以下内容提交到公开仓库：

- 真实 API Key 或包含密钥的配置文件
- 个人 RPG 存档和 `.rpgbox` 导出文件
- 没有再分发授权的立绘、背景和其他素材
- 含有私人剧情或敏感内容的调试截图
