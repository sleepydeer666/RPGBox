RPGBox 制作器（离线版）

使用方法：
1. 解压整个 PackageBuilder 目录。
2. 双击 index.html。
3. 在浏览器中制作并下载 .rpgbox 或 .role.rpgbox 文件。

点击右上角“导入并编辑”，可以打开已有的 RPG 剧本包或人物包并继续修改。

本目录不需要联网，也不需要启动 Web 服务。立绘和剧本内容只在当前浏览器中处理。
建议使用最新版 Chrome 或 Edge，以获得目录批量导入支持。

窗口取色：点击人物颜色旁的吸管按钮，在浏览器弹窗中选择正在显示参考图片的窗口，
然后直接点击预览画面中的目标像素。共享画面仅在本机用于取色，选取后会立即停止。
